# Social Media Emotion Detection App

This Streamlit app predicts emotions from user input text using a Logistic Regression model and TF-IDF vectorizer.

## Model Info
- Trained on social media text dataset
- Uses Logistic Regression + TF-IDF

## How to Use
1. Enter text into the input box
2. Click **"Predict Emotion"**
3. See the predicted emotion and confidence score

## Files
- `app.py`: Main Streamlit app
- `logistic_regression_model.pkl`: Trained ML model
- `tfidf_vectorizer.pkl`: Fitted vectorizer
- `Social Media Emotion Dataset.csv`: Training dataset
- `requirements.txt`: Required Python packages
- 'Social_Media_Listening_.ipynb' : Full code
